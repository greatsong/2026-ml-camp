내 첫 웹앱 만들기

오늘 만드는 것 → 인터넷에 뜨는 내 웹앱 주소(○○.streamlit.app) 🎉

  1. 선생님이 준 저장소에서 오른쪽 위 Fork를 눌러요.
  2. share.streamlit.io에 들어가 Continue with GitHub로 로그인해요.
  3. Create app → 내 저장소 / main / app.py → Deploy!
  4. 1~2분 기다리면 내 주소가 떠요. 깃허브에서 app.py를 아래 코드로 바꿔 봐요.
복사 → app.py
import streamlit as st

st.title("○○의 첫 번째 앱")
st.write("안녕하세요! 제가 만든 첫 웹앱이에요. 🎉")
⚠️안 뜨면 파일 경로(app.py)와 브랜치(main)를 확인해요. 1~2분은 기다리기!

AI랑 앱 만들기

오늘 만드는 것 → 슬라이더·버튼이 있는 움직이는 앱

복사 → 자기소개 앱
import streamlit as st

st.title("나를 소개하는 앱")
name = st.text_input("내 이름은?")
age = st.slider("내 나이는?", 10, 19, 14)
food = st.selectbox("좋아하는 음식", ["떡볶이", "피자", "치킨", "마라탕"])

if st.button("소개 완성!"):
    st.write(f"저는 {age}살 {name}이고, {food}을(를) 가장 좋아해요!")
    st.balloons()

AI에게 부탁해 볼까요? 아래 프롬프트를 복사해 AI에게 붙여넣고, 나온 코드를 다시 앱에 붙여넣어요.

복사 → AI 프롬프트
스트림릿 앱 만들어 줘. 슬라이더로 숫자 두 개를 고르면, 두 수를 더한 값과 곱한 값을 보여 주는 앱이야. 초보자가 이해하기 쉽게 짧게.
복사 → AI 프롬프트
우리 반 친구 5명의 키 데이터를 막대그래프로 보여 주는 스트림릿 앱 만들어 줘. 이름과 키는 코드 안에 직접 넣어 줘.
⚠️AI가 준 코드는 꼭 실행해서 확인해요. AI도 가끔 틀려요!

데이터로 그래프 앱

오늘 만드는 것 → 내 관심 데이터로 표 + 그래프 대시보드

복사 → 대시보드 뼈대
import streamlit as st
import pandas as pd

st.title("내 데이터 대시보드")

# 선생님이 준 데이터 주소(CSV)를 붙여 넣어요
df = pd.read_csv("여기에_데이터_주소.csv")

st.subheader("데이터 미리 보기")
st.dataframe(df)

st.subheader("그래프")
st.bar_chart(df)
복사 → AI 프롬프트
df라는 데이터프레임이 있어. 열은 ‘월’과 ‘평균기온’이야. 이걸 꺾은선 그래프로 그리고 스트림릿에서 보여 줘. 제목은 ‘월별 기온’으로.
⚠️그래프 한 장이면 성공이에요! 욕심내지 말고 하나 완성하고 친구에게 주소를 보내요.

AI가 미래를 예측해요

오늘 하는 것 → 서울 기온으로 “2050년은 몇 도?” 예측 (Colab에서)

복사 → Colab 셀
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)        # X=연도, y=기온 → AI가 '선'을 학습

pred = model.predict([[2050]])
print("2050년 예측 기온:", round(pred[0], 1), "도")
복사 → AI 프롬프트
연도(X)와 평균기온(y) 데이터가 있어. 선형회귀 모델을 학습시키고, 산점도 위에 예측 직선을 함께 그려 줘. 그리고 2050년 예측 기온도 출력해 줘.
⚠️먼 미래 예측은 틀릴 수 있어요. ‘AI가 그은 선’을 너무 믿지는 말기!

AI가 분류하고, 댓글을 읽어요

오늘 하는 것 → AI로 분류 + 유튜브 댓글 요약·번역, 그리고 발표!

복사 → Colab 셀 (분류)
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier()
model.fit(X_train, y_train)        # 특징으로 '유형'을 학습

print("정확도:", model.score(X_test, y_test))
복사 → AI 프롬프트 (요약)
이 댓글들을 한국어로 세 줄로 요약해 줘. 사람들이 가장 많이 말한 점 위주로.
복사 → AI 프롬프트 (번역)
영어로 된 댓글만 골라 한국어로 자연스럽게 번역해 줘.
⚠️정확도가 99%여도 함정일 수 있어요. ‘무엇을 놓치면 더 큰일일까?’ 생각해 봐요.
